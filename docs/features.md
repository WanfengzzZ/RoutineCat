# 功能模块介绍

## 1. 专注计时

- 25 分钟起，可调；息屏、锁屏不算失败（手机往桌上一扣，计时照走）
- 中央毛线环随进度从 12 点顺时针涂色，末端毛线球边走边转
- 专注完成时陪伴猫出现在环中央
- 没有暂停键——动作只有「开始」和「放弃」

## 2. 走步换盒

- 走够 8000 步，掉一个盲盒（首个盒子 4000 步）
- 自动读取当日步数，无需手动填报

## 3. 开盒

- 天地盖礼盒：摇盒 → 揭盖 → 光晕 → 猫浮出 → 身份卡，约 3.2 秒
- 新猫有彩纸与「新伙伴」标签；重逢猫折算为猫薄荷
- 开盒结果直接进入猫舍

## 4. 猫咪图鉴

- 84 只猫，7 个系列（英短、布偶、暹罗、田园、美短、缅因、加菲）
- 三档稀有度：N 普通 / R 隐藏 / SP 特别
- 未解锁的隐藏款与特别款显示「待揭晓」封印，不剧透形象
- 支持按系列、款式、佩戴、拥有状态筛选

## 5. 拍立得猫舍

- 首页拍立得展示陪伴猫
- 在猫图上左右滑动「摸摸头」，亲密度 +1（每日上限 5 次）
- 可切换陪伴猫

## 6. 饰品装扮

- 5 个部位：头顶、脸、脖子、肩背、猫舍
- 10 款手绘饰品：蝴蝶结、小鱼干、猫薄荷罐、铃铛项圈、毛线帽、圆框眼镜、格纹围巾、雏菊花环、星空披肩、奶油小皇冠
- 戴上后进入编辑态：可拖动位置、无级旋转、缩放 0.6~2.5 倍
- 装扮同步显示在专注页

## 7. 打卡与猫薄荷

- 打卡攒猫薄荷，连续打卡才送盲盒
- 断签清零连续天数，但已获得的猫、猫薄荷、图鉴进度全部保留
- 每周一张免断护盾（周一补、不累积）
