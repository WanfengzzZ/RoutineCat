# 猫猫图鉴（节选）

84 只猫，7 个系列，三档稀有度。这里展示部分已公开的猫咪立绘。

## 稀有度

| 档位 | 名称 | 说明 |
|---|---|---|
| N | 普通款 | 多数猫，名字多是吃的 |
| R | 隐藏款 | 每系列第 11 只，立绘更精致 |
| SP | 特别款 | 每系列第 12 只，工笔白描「掌中萌物」 |
